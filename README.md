NEON BREACH is a neon-lit arena FPS built with three.js. Rogue training drones have taken the arena — clear all five rounds, earn credits for every drone down, and spend them in the armory between rounds on a Ripper SMG, a Scattergun, a piercing Lance railgun, armor plates and stacking overclocks. Three drone types (fast Spark zappers, long-range Stinger gunners, heavy Bulwark bruisers) with telegraphed attacks, a full HUD, kill feed, synthesized WebAudio sound, and zero network requests.

## Run it

```sh
git clone https://github.com/lmingfei856-hue/makefun-best-game-01
cd makefun-best-game-01
node serve.ts
# open http://localhost:8080/game/
```
